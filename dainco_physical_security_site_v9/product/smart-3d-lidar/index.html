개요

제품 요약

Smart 3D LiDAR는 카메라 영상 대신 3D 포인트 클라우드 기반으로 보안 구역을 정의하고 침입을 감지하는 장비입니다.

강점은 프라이버시 보호(익명화된 3D 데이터)와 악천후/조도 변화에 대한 강인성입니다. 또한 PoE 기반으로 설치가 단순하고, 회전 부품이 없는 구조로 유지보수 부담을 줄이는 방향을 제시합니다.

핵심 포인트
  • Precise 3D zone placement: 드래그&드롭으로 3D 보안 구역을 설정하고, 방향성(Direction)까지 반영 가능합니다.
  • Rule-based alarm: 실제 객체 크기 기반으로 소동물을 필터링하고, 식생(바람에 흔들리는 나뭇잎 등) 같은 오경보 원인을 제외하는 규칙을 구성할 수 있습니다.
  • 악천후(비/눈/안개) 및 강한 햇빛 환경에서 동작하도록 IP67 등급으로 제시됩니다.
  • 표준 인터페이스: TCP/IP & MQTT로 VMS 또는 Web I/O로 연동하고, ONVIF 호환을 제공합니다.
  • Frame rate는 구성된 스캔 패턴에 따라 1–50 Hz로 제시됩니다.

적용 분야

대표 적용 시나리오

  • Fence monitoring: 펜스 접근/월담 시도 감지, 프리알람 구역으로 행동 패턴 조기 탐지
  • Gate monitoring: 출입 게이트/차단기 주변의 무단 접근·침입 감지
  • Open-area intrusion: 개활지 구역 침입 감지(악천후 환경 포함)
  • Railway/traffic monitoring: 철도/교차로/주요 인프라 구역 감시
Finder에서 위치파악 제품 보기 추천 솔루션
통합/연동

관제/플랫폼 연결 포인트

  • VMS 연동: TCP/IP 또는 MQTT로 이벤트/상태를 전달하는 구조를 설계할 수 있습니다.
  • Web I/O 연동: TCP/IP & MQTT로 외부 I/O 시스템과 연결 옵션을 고려할 수 있습니다.
  • ONVIF 호환: 기존 영상 생태계와의 접점을 확보(현장 정책에 맞춰 적용)
  • 운영 정책: Pre‑alarm/Alarm 다중 존을 관제 워크플로우와 연결하면 대응 품질이 올라갑니다.
웹사이트 운영 관점
연동 정보(프로토콜/인터페이스/지원 VMS)는 제품 스펙 필드로 관리하면, 검색/필터에 바로 반영됩니다.
