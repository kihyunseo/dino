개요

제품 요약

Senstar MultiSensor는 AI 기반 멀티 센싱을 통해 ‘오경보(nuisance alarm)’와 ‘상황 인지(situational awareness)’ 문제를 동시에 해결하는 것을 목표로 하는 경계 감지 장비입니다.

복수 센서(레이더, PIR, 영상분석 등)의 정보를 실시간으로 결합(센서 퓨전)하여, 비/눈/안개/헤드라이트/그림자/바람/진동 등 환경 교란을 배제하고 실제 위협에 집중합니다.

핵심 포인트
  • Sensor Fusion Engine이 여러 센서 신호를 종합해 ‘진짜 침입’과 환경성 교란을 구분하는 방향으로 동작합니다.
  • 구역을 Pre‑alarm / Alarm로 나눠 운영할 수 있어, 경보 과부하를 줄이고 보안 인력의 대응 품질을 올립니다.
  • Rugged 설계(하우징/마운트)로 현장 설치가 단순하며, PoE 기반으로 기존 네트워크 인프라를 재활용하기 좋습니다.
  • 영상은 RTSP로 스트리밍해 기존 VMS에 연결할 수 있으며, 알람은 Network Manager 게이트웨이를 통해 전달하는 구조를 구성할 수 있습니다.
  • UCM(Universal Configuration Module)을 통해 설정/진단/펌웨어 업데이트를 수행하는 운영 방식이 제시됩니다.

온도 범위–40 to +60 °C
방수/방진IP54
전원PoE · 3W(max)
무게0.6 kg (1.3 lbs)
크기18 × 19 × 10 cm
영상RTSP 스트리밍
설치통합 마운팅 브라켓(보안 스크류)
운영 개념Pre‑alarm/Alarm zone + 센서 퓨전
운영 팁
스펙은 문장 대신 “값”으로 관리하면, Finder(필터)·검색·비교표 생성이 자동화됩니다.
적용 분야

대표 적용 시나리오

  • 게이트/출입구: 차량·보행자 혼재 환경에서 오경보 억제
  • 펜스/외곽: 알람 후 확인(영상)까지 한 흐름으로 구성
  • 개활지: 넓은 구역에서 상황 인지 강화(프리알람 활용)
  • 건물 외곽/중요 구역: 접근/침입 시도 조기 감지
Finder에서 위치파악 제품 보기 추천 솔루션
통합/연동

관제/플랫폼 연결 포인트

  • 영상: 어떤 RTSP 클라이언트로도 영상 확인 가능(기존 VMS 연계 용이)
  • 알람: Network Manager가 게이트웨이로 동작하며 보안 시스템으로 알람 전달
  • VMS/SMS: Genetec, Milestone 등 게이트웨이 연동 옵션(알람 전달 중심) 고려
  • 설정/업데이트: UCM(Universal Configuration Module)로 구성/펌웨어 업데이트
웹사이트 운영 관점
연동 정보(프로토콜/인터페이스/지원 VMS)는 제품 스펙 필드로 관리하면, 검색/필터에 바로 반영됩니다.
